# Pedro Ribeiro · Portfólio

Portfólio profissional de freelancer: SEO, sites, tráfego pago e processos.
Publicado na Vercel em https://pedroribeiro.click

## Arquivos

- `index.html`: a página (HTML e CSS puro), com SEO, dados estruturados (Schema.org) e Google Tag Manager (GTM-NJ9522X7)
- `img/`: foto, imagem de prévia para redes sociais (`og-image.jpg`) e ícone
- `favicon.svg`: ícone da aba do navegador
- `robots.txt` e `sitemap.xml`: orientam o Google na indexação
- `llms.txt`: resumo do portfólio para ferramentas de IA
- `vercel.json`: redireciona `www` e `pedroharibeiro.vercel.app` para o domínio principal e define cache

A versão anterior (página de links estilo Linktree) continua no histórico do Git.
